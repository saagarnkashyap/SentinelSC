## Overview

**SentinelSC** is an enterprise-inspired supply chain intelligence platform built to demonstrate modern inventory optimization, analytics, and decision support using **fully synthetic semiconductor supply chain data**.

The long-term vision is to evolve SentinelSC into a complete **Supply Chain Control Tower** capable of:

* Inventory Optimization
* Supply Planning
* Digital Twin Simulation
* Event-Driven Architecture
* AI-powered Decision Support
* Real-time Supply Chain Monitoring

The current release (**v1.0**) focuses on building a solid inventory optimization foundation before expanding into advanced planning and AI capabilities.

---

## Current Features (v1.0)

* Synthetic semiconductor inventory dataset generator
* Economic Order Quantity (EOQ) calculation
* Safety Stock calculation
* Reorder Point (ROP) calculation
* Interactive Streamlit dashboard
* Plotly visualizations
* KPI metrics
* Modular Python architecture
